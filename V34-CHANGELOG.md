# V34 — Apex Gameplay Expansion

Gameplay-focused update. Existing buttons, panels, and site color system were left unchanged.

## Added
- Daily rotating gameplay events: Rift Rush, Gem Storm, Guardian Hunt, Elite Surge, and Phase Shift.
- New in-run power-ups: Shield, Fury, Magnet, and Energy.
- Power-up pickups with visible in-game effects.
- Gem Magnet temporarily pulls nearby gems toward the player.
- Daily event progress and once-per-day reward persistence.
- Event-specific gameplay modifiers and bonus rewards.
- Extra event-driven enemy, elite, gem, guardian, and power-up spawns.
- Daily event banner rendered inside the gameplay canvas.

## Compatibility
- Keeps the existing `game-v24.js` engine as the base.
- Keeps the existing redeem-code persistence bridge.
- Keeps the existing UI controls and panel styling unchanged.
